All linked source documentation is included in this repository and its source
archive. The runtime wheel does not contain the full Markdown tree; use this
repository or unpack the `.tar.gz` source package to browse it offline.

The dated research reports preserve earlier names, local artifact paths and
measurements. They do not assert that those private artifacts are distributed or
that every device has been validated.
